### Key Highlights

* Author and maintainer of <strong>Code-XR</strong>, a VS Code extension for immersive software visualization using <strong>TypeScript, Python, WebXR, A-Frame and BabiaXR</strong>.
* Published in <strong>IEEE Xplore</strong> after being accepted at <strong>IEEE VISSOFT 2025</strong>, with DOI <strong>10.1109/VISSOFT67405.2025.00034</strong>.
* Recipient of the <strong>Distinguished Artifact Award</strong> at VISSOFT 2025.
* Released <strong>Code-XR v1.1.0</strong>, improving performance, collaborative rooms, virtual screens, metric remapping and file/directory/project workflows.
* Currently evolving Code-XR with deeper software metrics, file relationships, commit/branch comparison and remote collaboration.
* Experience as a <strong>Junior Full-Stack Developer</strong> at <strong>VBGroup</strong>, contributing to an internal Online Booking Tool.
* Experience in <strong>Cloud & Systems N2</strong> at <strong>SATEC_</strong>, supporting monitored systems and infrastructure operations.
* Received <strong>Academic High Distinctions</strong> in projects related to Android/Kotlin development, C++ object-oriented design and telematic systems.
